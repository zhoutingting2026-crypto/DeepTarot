# DeepTarot · AI 塔罗

一个把塔罗抽牌、问题联想和 AI 解读结合起来的网页项目。希望用户可以带着一个问题开始，通过抽牌、阅读解读和继续交流，梳理自己的想法。

**[在线体验](https://deeptarot.up.railway.app)**

> 本项目用于娱乐与自我探索，解读不代表确定预测，也不替代医疗、法律或投资等专业建议。网站使用 Railway Free 部署，闲置休眠后的首次打开可能需要稍等。

## 可以做什么

- **两种牌阵**：单张指引，以及区分过去、现在和未来的三张牌阵；支持正位与逆位。
- **问题联想**：围绕工作、财富、感情、选择、身心状态和人际关系提供问句建议，支持“我想”“我怎么”等常见开头。
- **交互抽牌**：左右浏览牌堆，点选卡牌，播放抽牌和翻牌动画。
- **完整解读**：整体分析、关键词、深度拆解和行动建议默认展开。
- **继续交流**：围绕本次问题和牌阵追问。
- **明暗主题**：夜间深蓝金色、明亮奶油麦色，牌背随主题切换。
- **等待反馈**：水晶球呼吸动画与等待进度，生成期间锁定背景操作。

## AI 如何接入

网页将问题和抽牌信息发送到 Node.js 后端，再由后端调用阿里云百炼应用。百炼失败或返回内容不符合要求时，若配置了 DeepSeek，则尝试备用服务。页面标明最终采用的生成来源。

AI 在服务商的平台运行，本项目的服务器主要负责网页托管、请求转发和密钥保护。

```text
浏览器 → Node.js 后端 → 百炼应用
                    ↘ DeepSeek 备用接口
```

服务商密钥保存在服务器环境变量中，不会随网页发送给访问者。不要把真实 .env 文件提交到仓库。

## 技术与目录

使用原生 HTML、CSS、JavaScript 和 Node.js，无需前端框架。牌背使用 SVG，水晶球为生成式图像素材。

| 文件 | 用途 |
| --- | --- |
| output.html | 已构建的网页，包含牌面数据和视觉资源 |
| server.js | 服务启动入口 |
| server-runtime.cjs | 网页托管、AI 接口、输入校验、超时和频率限制 |
| question-bank.js | 按主题组织的问题题库 |
| reading-ui.js / reading-ui.css | 问题联想和等待交互源码参考，页面中已内嵌构建结果 |
| .env.example | 环境变量名称示例，不含密钥 |
| DEPLOYMENT.md | Railway 部署与本地运行说明 |

这个仓库存放发布版本；单独修改辅助 JS/CSS 文件不会自动改变已内嵌的网页，需要同步构建结果到 output.html。

## 本地运行

安装 Node.js 22 或更新版本，复制 .env.example 为 .env，填写自己的凭证后运行：

```bash
npm start
```

浏览器打开 `http://localhost:3000`。详细环境变量和 Railway 设置见 [部署说明](DEPLOYMENT.md)。
